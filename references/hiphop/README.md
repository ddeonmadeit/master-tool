# Genre references

Drop one or more **commercially-mastered hip-hop / trap / R&B** reference tracks
here as `.wav` (or `.aiff` / `.flac`). The app uses the first one (alphabetical)
as the Matchering reference in **Genre reference** mode.

- Pick a reference in the **same genre and tempo range** as your song.
- Prefer high-quality, **not heavily lossy** files (a clean WAV beats a low-bitrate MP3).
- If this folder is empty, Genre-reference mode automatically falls back to
  **Fully automatic** mastering and shows a notice.

> **Do not commit copyrighted tracks.** References are user-supplied and stay
> local; none are bundled with this project (see the licensing note in the
> top-level README).
